# El Códice de Álgebra

Juego web en español para aprender álgebra universitaria resolviendo problemas de aplicación y construyendo demostraciones. Cada teorema que demuestras entra al Códice y se vuelve una herramienta para demostrar el siguiente.

**Estado: Fase 2.** Mundo 1 (Fundamentos) completo: seis niveles (lógica, cuantificadores y conjuntos, relaciones, funciones, métodos de demostración, inducción), 28 teoremas con sus demostraciones y el jefe «El Guardián del Principio». Los Mundos 2 a 8 aparecen «en construcción».

- Diseño: [`docs/diseno.md`](docs/diseno.md) · Revisión matemática: [`docs/revision-matematica.md`](docs/revision-matematica.md) · Agregar contenido: [`docs/agregar-contenido.md`](docs/agregar-contenido.md)
- Jugar: abre `index.html` (un solo archivo, sin red).
- Desarrollo: edita `src/` y ejecuta `node build.js`. Pruebas: `node tools/test.js`, `node tools/contraste.js`, `node tools/auditar.js`.
