# El Códice de Álgebra

Juego web en español para aprender álgebra universitaria resolviendo problemas y construyendo demostraciones. Cada teorema demostrado entra al Códice y pasa a ser una herramienta para demostrar el siguiente.

**Estado: Fase 0 (diseño).** Todavía no hay juego: el documento de diseño está en [`docs/diseno.md`](docs/diseno.md) y espera revisión.

Mundos previstos: 1 Fundamentos · 2 Números · 3 Polinomios · 4 Matrices y sistemas · 5 Espacios vectoriales · 6 Transformaciones lineales · 7 Valores propios y producto interno · 8 Estructuras algebraicas.
